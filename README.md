# France Couverture

Site français en React, TypeScript, Tailwind CSS, Vite et Framer Motion. Le projet et ses routes sont conservés.

- `npm install` puis `npm run dev` pour le développement.
- `npm test` pour les tests du transport de demandes.
- `npm run build` pour le contrôle TypeScript et la compilation statique dans `dist`.
- `npm run check:launch` pour identifier les paramètres indispensables au lancement public.

Voir `docs/PRODUCTION-STATUS.md` pour les vérifications, limitations et informations requises. Le service de réception n’est pas configuré : aucun envoi n’est permis ; le contact téléphonique reste disponible.

Les photographies locales et leurs licences sont répertoriées dans `src/photos.json`. La galerie est modifiable dans `src/gallery.json`. Les polices locales disposent de leurs licences OFL dans `public/fonts`.
